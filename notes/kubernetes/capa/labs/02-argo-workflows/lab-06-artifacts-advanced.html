Lab 06: Artifacts, Advanced

Follow-up to lab 04: artifacts in a DAG, file mode, archive options. Needs the artifact repository from lab 04.

Syntax recap

outputs:
  artifacts:
  - name: result-data
    path: /tmp/output.txt
inputs:
  artifacts:
  - name: source-data
    path: /tmp/input.txt
  • steps: from: "{{steps.<step>.outputs.artifacts.<name>}}"
  • dag: from: "{{tasks.<task>.outputs.artifacts.<name>}}"

Artifacts in a DAG

apiVersion: argoproj.io/v1alpha1
kind: Workflow
metadata:
  generateName: dag-artifact-
spec:
  serviceAccountName: argo
  entrypoint: dag-example
  templates:
  - name: dag-example
    dag:
      tasks:
      - name: generate
        template: create-data
      - name: process-a
        dependencies: [generate]
        template: processor
        arguments:
          artifacts:
          - name: input-data
            from: "{{tasks.generate.outputs.artifacts.dataset}}"
          parameters:
          - {name: processor-name, value: A}
      - name: process-b
        dependencies: [generate]
        template: processor
        arguments:
          artifacts:
          - name: input-data
            from: "{{tasks.generate.outputs.artifacts.dataset}}"
          parameters:
          - {name: processor-name, value: B}
      - name: aggregate
        dependencies: [process-a, process-b]
        template: aggregator
        arguments:
          artifacts:
          - name: result-a
            from: "{{tasks.process-a.outputs.artifacts.result}}"
          - name: result-b
            from: "{{tasks.process-b.outputs.artifacts.result}}"

  - name: create-data
    container:
      image: busybox:1.36
      command: [sh, -c]
      args: ["echo 'raw dataset' > /tmp/dataset.txt"]
    outputs:
      artifacts:
      - {name: dataset, path: /tmp/dataset.txt}

  - name: processor
    inputs:
      artifacts:
      - {name: input-data, path: /tmp/input.txt}
      parameters:
      - name: processor-name
    container:
      image: busybox:1.36
      command: [sh, -c]
      args:
      - |
        echo "{{inputs.parameters.processor-name}} processed:" > /tmp/result.txt
        cat /tmp/input.txt >> /tmp/result.txt
    outputs:
      artifacts:
      - {name: result, path: /tmp/result.txt}

  - name: aggregator
    inputs:
      artifacts:
      - {name: result-a, path: /tmp/a.txt}
      - {name: result-b, path: /tmp/b.txt}
    container:
      image: busybox:1.36
      command: [sh, -c]
      args: ["cat /tmp/a.txt /tmp/b.txt"]

argo submit -n argo dag-artifact.yaml --watch
argo logs -n argo @latest
  • process-a and process-b run in parallel, both read the same artifact
  • parameters and artifacts go in the same arguments

File mode and archive

  - name: generate-script
    container:
      image: busybox:1.36
      command: [sh, -c]
      args:
      - |
        printf '#!/bin/sh\necho script ran\n' > /tmp/script.sh
        chmod +x /tmp/script.sh
    outputs:
      artifacts:
      - name: executable
        path: /tmp/script.sh
        archive:
          none: {}

  - name: run-script
    inputs:
      artifacts:
      - name: script
        path: /tmp/script.sh
        mode: 0755
    container:
      image: alpine:3.20
      command: [sh, -c]
      args: ["/tmp/script.sh"]
  • mode on the input artifact sets permissions, otherwise Permission denied when executing (mode isn’t preserved when archive is none)
  • archive.none: {} skips tar.gz, good for files that are already compressed or big
  • wired up with a normal two-step steps template using from: "{{steps.create-script.outputs.artifacts.executable}}"

Validating JSON from an artifact

  - name: parse-json
    inputs:
      artifacts:
      - {name: data, path: /tmp/input.json}
    container:
      image: python:3.12-slim
      command: [python, -c]
      args: ["import json; print(json.load(open('/tmp/input.json')))"]
  • the producer just writes {"status": "success", "count": 42} to /tmp/data.json and declares it as an output
  • argo wait @latest && argo logs @latest

Troubleshooting notes

  • Failed to save artifact = no artifact repository configured (artifactRepository key in workflow-controller-configmap, see lab 04)
  • Permission denied on an artifact script = set mode
  • args: must be a list, args: | followed by - | is invalid yaml for a container
