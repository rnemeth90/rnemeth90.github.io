Argo Workflows

1

Main purpose of Argo Workflows?

  • A. Continuous delivery for k8s apps
  • B. Orchestrate parallel/sequential containers on k8s
  • C. Progressive delivery
  • D. Trigger workflows from events
Answer

B - container-native workflow engine. A is CD, C is Rollouts, D is Events.

## 2 Which template type defines parallel execution with dependencies? - A. Steps - B. DAG - C. Container - D. Suspend
Answer

B - DAG tasks declare dependencies (or depends) and run as soon as those finish.

## 3 Purpose of `retryStrategy`? - A. Retry the whole workflow - B. Retry a specific step/task on failure - C. Schedule periodic runs - D. Backoff for API calls only
Answer

B - set on a template; limit, retryPolicy (Always, OnFailure, OnError, OnTransientError), backoff.

## 4 Command to submit a Workflow from a file? - A. `argo create workflow.yaml` - B. `argo submit workflow.yaml` - C. `argo run workflow.yaml` - D. `argo start workflow.yaml`
Answer

B - argo submit. The others are not argo commands.

## 5 What does this do? ```yaml steps: - - name: step1 template: whalesay - - name: step2a template: whalesay - name: step2b template: whalesay ``` - A. All three sequentially - B. All three in parallel - C. step1, then step2a and step2b in parallel - D. Invalid syntax
Answer

C - outer list = sequential groups, inner list = parallel.

## 6 Which is NOT a supported artifact repository? - A. S3 - B. GCS - C. Redis - D. Azure Blob Storage
Answer

C - supported: S3 (and compatibles like MinIO), GCS, Azure Blob, Artifactory, HDFS, OSS, Git, HTTP.

## 7 Purpose of `when`? - A. Schedule a workflow - B. Conditionally run a step/task - C. Set a step timeout - D. Define artifact upload time
Answer

B - e.g. when: "{{steps.step1.status}} == Succeeded".

## 8 Which field limits total workflow run time? - A. `spec.timeout` - B. `spec.activeDeadlineSeconds` - C. `spec.deadline` - D. `spec.ttlStrategy.secondsAfterCompletion`
Answer

B - workflow is terminated when exceeded. ttlStrategy is cleanup after completion.

## 9 What is a WorkflowTemplate? - A. Reusable, namespaced workflow definition referenced by other workflows - B. Template for generating workflows from events - C. A container template inside a workflow - D. A Helm template for Argo Workflows
Answer

A - referenced via workflowTemplateRef or templateRef. ClusterWorkflowTemplate is the cluster-scoped version.

## 10 How to pass a step's output to another step? - A. Env vars - B. `{{steps.stepname.outputs.result}}` - C. ConfigMaps - D. Not possible
Answer

B - also {{steps.name.outputs.parameters.param}}. In a DAG use tasks.name.

## 11 Which template type pauses until resumed? - A. Pause - B. Suspend - C. Wait - D. Manual
Answer

B - resume with argo resume or duration; useful for approval gates.

## 12 Purpose of input/output parameters? - A. Scheduling - B. Pass data/config between templates - C. Resource requests - D. Artifact locations
Answer

B

## 13 Command for workflow logs? - A. `kubectl logs workflow-name` - B. `argo logs workflow-name` - C. `argo workflow logs workflow-name` - D. `argo get workflow-name --logs`
Answer

B - argo logs <wf> [pod]; -f to follow.

## 14 What does `parallelism` control? - A. Workflow replicas - B. Max pods running at once - C. CPU per pod - D. Number of steps defined
Answer

B - can be set on the workflow or on a template (limits its children).

## 15 What is a CronWorkflow? - A. Workflow run on a schedule - B. Workflow using cron containers - C. Workflow with time-based retry - D. Workflow that monitors CronJobs
Answer

A - like a CronJob; spec.schedule (cron syntax) plus workflowSpec.

# Argo CD

16

What does RespectIgnoreDifferences do?

  • A. Ignores all differences
  • B. Honors ignoreDifferences during sync
  • C. Blocks sync when diffs exist
  • D. Ignores resource deletion
Answer

B - sync option; ignored fields are not overwritten on sync.

## 17 Which lists all applications? - A. `argocd app list` - B. `argocd app get --all` - C. `kubectl get applications -n argocd` - D. A and C
Answer

D - the CLI via the API, kubectl via the Application CRs (if they live in argocd).

## 18 Kustomize app with overlays: how to pick the overlay? - A. `source.kustomize.overlay` - B. `source.path` pointing at the overlay dir - C. `source.targetRevision` - D. AppProject config
Answer

B - Argo CD detects kustomization.yaml in the path.

## 19 Purpose of `argocd.argoproj.io/sync-wave`? - A. Order resources are synced - B. Group resources for batch ops - C. Number of sync attempts - D. Sync frequency
Answer

A - lower waves first (default 0, can be negative); waits for health before next wave.

## 20 How can you preview a sync without applying it? - A. `argocd app diff` - B. `argocd app sync --dry-run` - C. `argocd app wait` - D. A and B
Answer

D

## 21 Deploy to a namespace that doesn't exist yet? - A. Create it by hand - B. Sync option `CreateNamespace=true` - C. `destination.createNamespace: true` - D. Not supported
Answer

B - under syncPolicy.syncOptions.

## 22 What does OutOfSync mean? - A. Sync failed - B. Git (desired) differs from live state - C. App is unhealthy - D. Repo unreachable
Answer

B - not necessarily a problem; sync status is separate from health.

## 23 Primary role of the Application Controller? - A. AuthN/AuthZ - B. Poll Git for changes - C. Compare desired (Git) with live state - D. Serve UI/API
Answer

C - repo server handles Git/manifests, API server handles auth/UI.

## 24 Which setting syncs automatically on drift from manual cluster changes? - A. `automated.prune: true` - B. `automated.selfHeal: true` - C. `automated.allowEmpty: true` - D. `syncOptions: [AutoSync=true]`
Answer

B - prune deletes resources removed from Git.

## 25 Keep a Secret from being deleted on sync? - A. `sync-options: Delete=false` - B. `compare-options: IgnoreDuringDeletion` - C. `sync-options: Prune=false` - D. `tracking-id: ignore`
Answer

C - annotation argocd.argoproj.io/sync-options: Prune=false.

## 26 Show diff between Git and live state? - A. `argocd app status myapp` - B. `argocd app diff myapp` - C. `argocd app get myapp --show-params` - D. `argocd app history myapp`
Answer

B

## 27 App stuck in Progressing - most likely cause? - A. Repo unreachable - B. A resource hasn't become healthy yet - C. Bad YAML - D. Sync cancelled
Answer

B - e.g. Deployment not reaching ready replicas.

## 28 Purpose of the `project` field? - A. Git project of manifests - B. References an AppProject (repos, destinations, resource restrictions, roles) - C. Target namespace - D. Cosmetic grouping
Answer

B - defaults to default.

## 29 Skip schema validation on apply? - A. `Validate=false` - B. `SkipSchemaValidation` - C. `ServerSideApply=true` - D. `ApplyOutOfSyncOnly=true`
Answer

A

## 30 Best way to deploy one repo to many clusters? - A. One Argo CD per cluster - B. ApplicationSet with cluster generator - C. One repo per cluster - D. Helm values + manual sync
Answer

B

## 31 What does `health.status: Degraded` mean? - A. Sync failed - B. Resource has health problems (e.g. CrashLoopBackOff) - C. Out of sync - D. App was pruned
Answer

B - health values: Healthy, Progressing, Degraded, Suspended, Missing, Unknown.

## 32 Which component renders Helm/Kustomize/Jsonnet into manifests? - A. Application Controller - B. API Server - C. Repo Server - D. Redis
Answer

C

## 33 Exclude files from processing in a directory source? - A. `source.path` with negation - B. `source.directory.exclude` - C. `ignoreDifferences` - D. `ignoreFiles`
Answer

B - glob pattern; include is the inverse.

## 34 What does `argocd app wait` do? - A. Pause a sync - B. Block until app is synced and healthy - C. Delay a sync - D. Wait for confirmation
Answer

B - handy in CI; flags like --health, --sync, --timeout.

## 35 Which AppProject field restricts target namespaces? - A. `sourceRepos` - B. `destinations` - C. `clusterResourceWhitelist` - D. `namespaceResourceBlacklist`
Answer

B - cluster + namespace pairs.

## 36 Use a private repo over SSH? - A. Register repo credentials with the SSH private key - B. `source.sshKey` in the Application - C. Key in `argocd-cm` - D. SSH not supported
Answer

A - argocd repo add git@... --ssh-private-key-path; stored as a Secret labeled argocd.argoproj.io/secret-type: repository.

# Argo Rollouts

37

Command for rollout status and history?

  • A. kubectl get rollout name
  • B. kubectl argo rollouts get rollout name
  • C. kubectl describe rollout name
  • D. kubectl argo rollouts status name
Answer

B - shows steps, weights, replica sets, analysis runs. --watch to follow. status only reports progress/health.

## 38 What is an Experiment? - A. Test environment - B. Run one or more ReplicaSets side by side (optionally with analysis) for comparison - C. An analysis template type - D. Rollback strategy
Answer

B

## 39 Which strategy rolls back fastest? - A. Canary - B. Blue-Green - C. Rolling Update - D. Same
Answer

B - old ReplicaSet stays up for scaleDownDelaySeconds, so rollback is a service selector switch.

## 40 What is `abortScaleDownDelaySeconds`? - A. Delay before abort starts - B. Delay before scaling down the new ReplicaSet after an abort - C. Abort timeout - D. Blocks scaling during abort
Answer

B - default 30s; 0 disables scale down. Applies to blue-green and canary with traffic routing.

## 41 Where is the traffic router configured for canary? - A. `spec.strategy.canary.trafficManagement` - B. `spec.trafficRouting` - C. `spec.strategy.canary.trafficRouting` - D. `spec.networking.trafficManager`
Answer

C - providers: Istio, NGINX, ALB, SMI, Traefik, etc.

## 42 With a traffic router configured, what does this do? ```yaml steps: - setWeight: 20 - pause: {duration: 10m} - setWeight: 50 - pause: {duration: 10m} ``` - A. 20% traffic to canary, 10m, then 50%, 10m, then 100% - B. Fails without analysis - C. Needs manual promotion at each pause - D. Deploys 20% pods only
Answer

A - pause with a duration auto-continues; bare pause: {} waits for promote.

## 43 Primary purpose of Argo Rollouts? - A. Cluster upgrades - B. Progressive delivery (blue-green, canary) - C. Auto-rollback only - D. Workflow execution
Answer

B - replaces Deployment with a Rollout CRD.

## 44 What does `setWeight` do? - A. Percentage of traffic to canary - B. Canary replica count - C. Pod priority - D. Resource limits
Answer

A - without a traffic router it approximates by canary pod ratio.

## 45 Promote a paused rollout? - A. `kubectl argo rollouts promote name` - B. `kubectl rollout promote name` - C. `kubectl argo rollouts continue name` - D. `kubectl argo rollouts resume name`
Answer

A - --full skips remaining steps and analysis.

## 46 `activeService` vs `previewService` in blue-green? - A. Active = current version, preview = new version - B. Both load balance all versions - C. Active = prod, preview = monitoring only - D. Optional, monitoring only
Answer

A - selectors are swapped on promotion; previewService is optional.

## 47 Which metric providers does AnalysisTemplate support? - A. Prometheus - B. Datadog - C. Web - D. All of the above
Answer

D - also New Relic, Wavefront, CloudWatch, Kayenta, Job, Influx.

## 48 AnalysisRun fails during canary? - A. Continues - B. Pauses for manual input - C. Aborted, reverts to stable - D. Ignored
Answer

C - rollout goes Degraded; traffic shifts back to stable.

## 49 Blue-green with `autoPromotionEnabled: false`? - A. Disables auto-rollback - B. Waits for manual promotion after preview is ready - C. Disables analysis - D. Rollout won't start
Answer

B - default true promotes as soon as preview is ready.

## 50 Best strategy to test new version with a little real traffic? - A. Blue-Green - B. Canary - C. Rolling Update - D. Recreate
Answer

B

## 51 Purpose of `scaleDownDelaySeconds` in blue-green? - A. Delay deployment start - B. Delay scaling down the previous version after promotion - C. Promotion timeout - D. Delay analysis
Answer

B - default 30s; gives time for connections to drain and for fast rollback.

# Argo Events

52

What does this Sensor dependency set mean?

dependencies:
- name: webhook-dep
  eventSourceName: webhook
  eventName: example
- name: calendar-dep
  eventSourceName: calendar
  eventName: hourly
  • A. Either event triggers
  • B. Both events are required
  • C. Webhook fires, then waits for calendar
  • D. Invalid
Answer

B - default is AND. Use circuit/conditions for OR logic.

## 53 Which is NOT an EventSource type? - A. Kafka - B. Redis - C. PostgreSQL - D. GitHub
Answer

C

## 54 Primary purpose of Argo Events? - A. Monitor k8s Events - B. Trigger workflows/resources from events of many sources - C. Log events externally - D. Microservice framework
Answer

B

## 55 Two main components? - A. EventSource and Trigger - B. EventSource and Sensor - C. Webhook and Workflow - D. Source and Destination
Answer

B - plus the EventBus that carries events (NATS JetStream by default).

## 56 Which EventSource receives HTTP POST? - A. Webhook - B. HTTP - C. API - D. REST
Answer

A

## 57 What does a Sensor do when dependencies are met? - A. Logs the event - B. Executes triggers - C. Stops listening - D. Creates an EventSource
Answer

B

## 58 Trigger type to create a Workflow? - A. Workflow Trigger - B. Argo Workflow Trigger - C. K8s Resource Trigger - D. Custom Trigger
Answer

B - argoWorkflow trigger; the k8s resource trigger can also create arbitrary objects.

## 59 Purpose of event filters on a Sensor? - A. Block malicious events - B. Conditionally process events by payload/metadata - C. Rate limit - D. Encrypt
Answer

B - filters on data, time, context, expression.

## 60 Which EventSource handles MinIO bucket notifications? - A. S3 - B. Minio - C. Bucket - D. Storage
Answer

B - for AWS S3, use sns or sqs.
