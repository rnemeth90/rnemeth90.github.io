Argo Workflows

1

Purpose of a Container template?

  • A. Pull images
  • B. Define a single container to run
  • C. Build images
  • D. Manage registries
Answer

B - the basic template type: image, command, args, env.

## 2 What must be configured before using artifacts? - A. An artifact repository (S3, GCS, etc.) - B. Local filesystem - C. Docker registry - D. Nothing
Answer

A - default repo in the workflow-controller-configmap (artifactRepository) or per-namespace artifact-repositories ConfigMap.

## 3 What does `outputs.parameters` do? - A. Sends params to external systems - B. Exposes values (file, stdout, JSON path) to later steps - C. Writes params to logs - D. Validates inputs
Answer

B

## 4 Delete a completed Workflow? - A. `argo delete name` - B. `argo remove name` - C. `kubectl delete workflow name` - D. A and C
Answer

D - argo delete also supports --completed, --older.

## 5 Purpose of `withItems`? - A. Loop over a list, one run per item - B. Include multiple templates - C. Attach artifacts - D. List params
Answer

A - fan-out; withParam takes a JSON list, withSequence a number range.

## 6 What does memoization do? - A. Stores workflow history - B. Caches step outputs to skip identical re-runs - C. Lowers memory use - D. Backs up workflows
Answer

B - memoize.key + cache.configMap.

## 7 Which template type creates/patches a k8s resource and waits on a condition? - A. Container - B. Resource - C. Script - D. Suspend
Answer

B - action: create, apply, patch, delete; successCondition/failureCondition.

## 8 What is a WorkflowEventBinding? - A. Bind workflows to namespaces - B. Trigger a WorkflowTemplate when an event is POSTed to the Argo server events API - C. Bind events to steps - D. Connect to Kafka
Answer

B - /api/v1/events/{namespace}/{discriminator}; matched with event.selector.

## 9 Limit parallel pods at template level? - A. `parallelism` - B. `limit` - C. `concurrency` - D. Unsupported
Answer

A - on a steps/dag template it limits that template’s children.

## 10 What is the `exitCode` output? - A. Workflow exit status - B. Exit code of a container/script - C. k8s error code - D. Sync status
Answer

B - {{steps.name.exitCode}}/{{outputs.exitCode}}, only for container and script templates.

## 11 Flag to override a parameter on submit? - A. `-p` / `--parameter` - B. `--param` - C. `--override` - D. `--set`
Answer

A - argo submit wf.yaml -p msg=hi. --parameter-file for a file.

## 12 Purpose of workflow archive? - A. Compress logs - B. Persist completed workflows in Postgres/MySQL - C. Back up to object storage - D. Cut memory
Answer

B - needs persistence in the controller config; survives CR deletion.

## 13 Parameter substitution syntax? - A. `${parameter}` - B. `{{inputs.parameters.name}}` - C. `#{parameter}` - D. `$parameter`
Answer

B

## 14 By default, what happens when a DAG task fails? - A. Workflow keeps scheduling all independent tasks - B. No new tasks are scheduled; running ones finish and the workflow fails - C. Auto retry - D. Pauses for manual input
Answer

B - failFast: true is the default. Set failFast: false to let independent branches finish; dependents are always skipped.

## 15 CronWorkflow schedule field? - A. `spec.schedule` - B. `spec.cron` - C. `spec.cronExpression` - D. `spec.timing`
Answer

A - newer versions also accept spec.schedules (list).

# Argo CD

16

Which component generates manifests from Helm?

  • A. Application Controller
  • B. Repo Server
  • C. API Server
  • D. Dex
Answer

B

## 17 What does `Replace=true` do? - A. Replaces all resources in the namespace - B. Uses `kubectl replace` instead of `apply` - C. Replaces changed resources only - D. Replaces the Application
Answer

B - for resources that are too large for apply annotations; destructive.

## 18 How to stop pruning? - A. `syncPolicy.automated.prune: false` - B. Annotation `argocd.argoproj.io/sync-options: Prune=false` on a resource - C. Remove the Application - D. A and B
Answer

D - app-wide vs per-resource.

## 19 What does `argocd app sync --dry-run` do? - A. Test Git connectivity - B. Preview changes without applying - C. Validate YAML - D. Check health
Answer

B

## 20 Which status means fully operational? - A. Synced - B. Healthy - C. Running - D. Ready
Answer

B - Synced is the sync status, Healthy is the health status.

## 21 Destination namespace doesn't exist and no `CreateNamespace`? - A. Auto-created - B. Sync fails - C. Uses `default` - D. Stuck Progressing
Answer

B

## 22 Field to ignore differences in specific fields? - A. `spec.ignoreFields` - B. `spec.ignoreDifferences` - C. `spec.compareOptions` - D. `spec.diffOptions`
Answer

B - jsonPointers, jqPathExpressions, managedFieldsManagers.

## 23 What is an ApplicationSet? - A. Group of apps - B. Template that generates many Applications via generators - C. Collection of AppProjects - D. Set of sync policies
Answer

B

## 24 Which generator creates apps from repo directories? - A. Directory - B. Git - C. List - D. Cluster
Answer

B - Git generator has directories and files modes.

## 25 What does refresh do? - A. Restarts pods - B. Re-fetch Git and re-compare with live state now - C. Updates the manifest - D. Clears cache
Answer

B - argocd app get myapp --refresh; --hard-refresh also invalidates the manifest cache.

## 26 Annotation that stops Argo CD deleting a resource? - A. `sync-options: Replace=true` - B. `sync-options: Prune=false` - C. `argocd.argoproj.io/protected: "true"` - D. `kubectl.kubernetes.io/prune: "false"`
Answer

B - Delete=false also exists to keep it when the app itself is deleted.

## 27 Purpose of sync waves? - A. Batch apps - B. Order resource creation in a sync - C. Retry attempts - D. Sync frequency
Answer

B - argocd.argoproj.io/sync-wave, lower first.

## 28 Show sync status and health of an app? - A. `argocd app list myapp` - B. `argocd app get myapp` - C. `argocd app describe myapp` - D. `argocd app info myapp`
Answer

B

## 29 What does `ServerSideApply=true` do? - A. Renders manifests on the server - B. Uses Kubernetes server-side apply - C. Calls the API server directly - D. Server-side validation
Answer

B - better field ownership and handles large CRDs.

## 30 Suspend auto-sync temporarily? - A. Remove `syncPolicy` - B. `syncPolicy.automated: null` - C. `argocd app set myapp --sync-policy none` - D. All of the above
Answer

D - re-enable with argocd app set myapp --sync-policy automated.

## 31 What is `argocd-cm`? - A. Stores Application manifests - B. Main Argo CD settings (URL, SSO/Dex config, resource customizations, timeouts) - C. Stores Git credentials - D. Manifest cache
Answer

B - repo creds are Secrets; RBAC is argocd-rbac-cm.

## 32 What does `Force=true` do? - A. Syncs even if already synced - B. Retries forever - C. Refreshes - D. Uses `kubectl apply --force` (delete and recreate when needed)
Answer

D - e.g. for immutable fields; can cause downtime.

## 33 Application's source repo is deleted? - A. App auto-deleted - B. `ComparisonError` - C. Uses cache forever - D. App suspended
Answer

B - last known state stays; nothing is deleted.

## 34 Which AppProject fields restrict resource kinds? - A. `namespaceResourceWhitelist` - B. `clusterResourceWhitelist` - C. `allowedResources` - D. A and B
Answer

D - blacklist variants exist too.

## 35 What does `PruneLast=true` do? - A. Prune at the end of sync, after other waves - B. Prune only the newest resources - C. Delay prune a cycle - D. Protect recent resources
Answer

A

## 36 Which component handles authentication? - A. Application Controller - B. API Server (with Dex for SSO) - C. Repo Server - D. Redis
Answer

B - local users and tokens are handled by the API server directly.

# Argo Rollouts

37

Which k8s resource does a Rollout replace?

  • A. StatefulSet
  • B. Deployment
  • C. DaemonSet
  • D. Job
Answer

B - similar spec; can also workloadRef an existing Deployment.

## 38 What does `maxSurge` control in a canary? - A. Max canary traffic % - B. Extra pods allowed above desired during update - C. Max evaluation time - D. Max steps
Answer

B - applies to canary without traffic routing (pod-ratio based).

## 39 Abort and revert a rollout? - A. `kubectl argo rollouts abort name` - B. `kubectl argo rollouts undo name` - C. `kubectl argo rollouts revert name` - D. `kubectl argo rollouts retry name`
Answer

A - retry re-runs an aborted rollout.

## 40 What is an AnalysisTemplate? - A. Metrics + success criteria definition - B. Workflow analysis - C. Cluster analysis - D. Strategy generator
Answer

A - ClusterAnalysisTemplate for cluster scope.

## 41 Which traffic provider uses a `VirtualService`? - A. NGINX - B. AWS ALB - C. Istio - D. Traefik
Answer

C - Rollouts edits route weights in the VirtualService.

## 42 What does `autoPromotionSeconds` do (blue-green)? - A. Promote N seconds after the new ReplicaSet is ready - B. Promote only if analysis passes - C. Promotion timeout - D. Delays rollback
Answer

A - used with autoPromotionEnabled: false.

## 43 Show rollout steps and progress? - A. `kubectl argo rollouts status name` - B. `kubectl argo rollouts get rollout name` - C. `kubectl argo rollouts describe name` - D. `kubectl get rollout name -o yaml`
Answer

B

## 44 Purpose of `analysis.args` in a strategy? - A. Args for analysis containers - B. Values for AnalysisTemplate args - C. Analysis frequency - D. Analysis timeout
Answer

B - e.g. valueFrom.podTemplateHashValue.

## 45 Which blue-green service gets production traffic? - A. Both - B. Active - C. Preview - D. A separate service
Answer

B

## 46 What does `pause: {}` do? - A. Pause until promoted - B. Skipped - C. Default duration - D. Invalid
Answer

A - kubectl argo rollouts promote name to continue.

## 47 Which metric provider runs k8s Jobs? - A. Prometheus - B. Job - C. Kubernetes - D. Custom
Answer

B - exit code decides success.

## 48 Purpose of `minPodsPerReplicaSet`? - A. Minimum pods for the Rollout - B. Keep at least N pods in each ReplicaSet during update - C. Min replica count - D. Validates pod count
Answer

B - canary with traffic routing; keeps stable and canary from scaling to zero.

## 49 Restart a Rollout? - A. `kubectl argo rollouts restart name` - B. `kubectl argo rollouts retry name` - C. `kubectl rollout restart rollout name` - D. `kubectl argo rollouts promote name --full`
Answer

A

## 50 Rollout spec changed but not the pod template? - A. No new rollout - B. New rollout starts - C. Error state - D. Pods restart
Answer

A - only template changes create a new ReplicaSet revision.

## 51 Which metric field sets how many failed measurements fail the metric? - A. `count` - B. `failureLimit` - C. `interval` - D. `initialDelay`
Answer

B - default 0; inconclusiveLimit and consecutiveErrorLimit (default 4) are separate.

# Argo Events

52

What does EventBus do?

  • A. Filters events
  • B. Transports events between EventSources and Sensors
  • C. Stores history
  • D. Routes to namespaces
Answer

B - NATS JetStream (default), NATS streaming (deprecated) or Kafka.

## 53 Which EventSource watches k8s resources? - A. K8s - B. Resource - C. Kubernetes - D. Watcher
Answer

B

## 54 How do you fire a trigger on a subset of dependencies? - A. `dependencyLogic` - B. `triggers[].template.conditions` - C. `spec.order` - D. `spec.validate`
Answer

B - e.g. conditions: "dep-a || dep-b". Without it all deps (AND) are needed.

## 55 Which trigger type creates arbitrary k8s resources? - A. `argoWorkflow` - B. `k8s` - C. `http` - D. `custom`
Answer

B - argoWorkflow is for Workflows only.

## 56 What does the `calendar` EventSource do? - A. Monitor calendar apps - B. Emit events on a cron schedule/interval - C. Sync external calendars - D. Manage timestamps
Answer

B

## 57 Which EventSource gets events from AWS SNS? - A. `sns` - B. `aws` - C. `amazon` - D. `pubsub`
Answer

A - pubsub is GCP; sqs is also available.

## 58 Purpose of data filters on a Sensor? - A. Block events - B. Transform events - C. Process events only when payload fields match - D. Validate schema
Answer

C - filters.data, with path, type, value.

## 59 Which protocols can the Webhook EventSource serve? - A. HTTPS only - B. HTTP only - C. HTTP and HTTPS - D. WebSocket
Answer

C - HTTPS needs serverCertSecret/serverKeySecret.

## 60 Sensor trigger fails? - A. Event lost - B. Retried per the trigger's `retryStrategy` - C. Sensor stops - D. EventSource notified
Answer

B - retryStrategy: steps, duration, factor, jitter.
